## 关于 Portcloud

Portcloud 是面向独立开发者与创业团队的开箱即用服务平台。

你需要的是一个服务，不是一台服务器。配置你需要的服务，其余基础设施交给 Portcloud，无需从零搭建和维护。

**如果只需要一个端口，不要为整台主机付费。**

我们提供可以直接使用、接入应用与工作流的能力，让你把时间留给产品和创造，而不是服务器与运维。

**开发者需要的是服务，不是服务器。**
