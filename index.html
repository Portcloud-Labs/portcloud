Built for Agents

所有服务，
都能接入你的 Agent。

Agent 接入不是某一个产品的专属功能，而是 Portcloud 所有服务的共同能力。让 Agent 在任务与工作流中使用你需要的服务。

为你的 Agent 选择服务→
01

每一项服务，都支持 Agent 接入

从 VPN、通知到 AI Gateway、Proxy、Chat 和 NAT VPS，Agent 接入能力覆盖整个服务目录。

02

每一项服务，都将提供对应 Skill

我们将为所有服务陆续提供对应的 Skill，让 Agent 了解如何接入与使用服务。

03

把服务能力带进 Agent 工作流

把服务接入 Agent，让服务能力成为任务执行的一部分，而不只是独立使用的工具。

Services, not servers

买你需要的能力，
不是一台等待配置的机器。

从你的实际需求出发，Portcloud 把能力变成可以直接使用的服务，而不是让你先买一台主机，再自己把它变成想要的东西。

01

选择能力，不选择机器配置

先看服务能帮你解决什么问题，而不是从 CPU、内存和容器开始。

02

接入使用，不从零部署

进入服务网站，按服务的接入方式配置使用。无需先部署你自己的服务实例。

03

专注你的应用和工作流

基础设施由 Portcloud 管理，你把精力留给真正想完成的事情。

少一套基础设施，多一点创造。
